# CalibraTrack – Calibration Management System

CalibraTrack is a web-based Calibration Management System designed to help manufacturing industries manage measuring instruments, schedule calibration activities, maintain calibration certificates, track maintenance work orders, and prevent the use of overdue or invalid instruments in production.

The system provides centralized instrument tracking, calibration history, certificate management, production usage validation, alerts, and audit records.

## 1. Key Features

- **Dashboard:** View instrument statistics, calibration results, certificates, and work order summaries.
- **Instrument Management:** Register instruments and manage their details and calibration status.
- **Instrument Types:** Manage instrument categories, measurement units, ranges, and accuracy.
- **Calibration Plans:** Define calibration intervals, tolerance limits, and effective dates.
- **Calibration Management:** Record calibration results and determine pass or fail outcomes.
- **Certificate Management:** Generate certificates for successfully calibrated instruments.
- **Work Order Management:** Create and track corrective maintenance activities for failed instruments.
- **Production Usage:** Record instrument usage and validate whether an instrument is eligible for production use.
- **Emergency Extensions:** Manage approved exceptions to calibration validity rules.
- **Alerts:** Monitor calibration failures, overdue instruments, and other important events.
- **Audit History:** Maintain records of important system activities.
- **Reports:** View operational information and export available records.

## 6. Installation and Setup

### Step 1: Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd CalibraTrack
```

Replace the URL with your actual public GitHub repository URL.

### Step 2: Install frontend dependencies

Run this command from the project root directory:

```bash
npm install
```

### Step 3: Install backend dependencies

```bash
cd server
npm install
```

### Step 4: Prepare the database

The backend uses the SQLite database generated by the data-generation module.

Ensure the following file exists:

```text
data-generator/output/calibratrack.sqlite
```

The backend connects to this database through `server/database.js`.

If the database is not included or needs to be generated again, return to the project root and run:

```bash
python data-generator/scripts/generate_data.py
```

Validate the generated dataset:

```bash
python data-generator/tests/validate_data.py
```

**Important:** Generate the database before starting the backend if the SQLite database file is unavailable.

## 7. Running the Application

CalibraTrack requires two running processes: the React frontend and the Express backend.

### Terminal 1 – Start the backend

Open a terminal in the project root:

```bash
cd server
npm run dev
```

The backend runs at:

```text
http://localhost:5000
```

API base URL:

```text
http://localhost:5000/api
```

### Terminal 2 – Start the frontend

Open another terminal in the project root:

```bash
npm run dev
```

The frontend runs at:

```text
http://localhost:5173
```

Open the frontend URL in your browser and log in using the demo credentials.

## 8. Application Workflow

1. Register an instrument and select its instrument type.
2. Assign an appropriate calibration plan.
3. Record calibration measurements and results.
4. If calibration passes, update the instrument's calibration validity and generate a certificate.
5. If calibration fails, create a maintenance work order.
6. Complete the impact assessment and corrective maintenance.
7. Perform post-maintenance verification through another calibration.
8. Record production usage and validate the instrument's calibration status.
9. Monitor alerts and review audit history.
